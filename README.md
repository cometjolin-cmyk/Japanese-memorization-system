# 日文一期中考前考衝刺複習測驗系統 🇯🇵

> 為日語初學者與大學日文一期中考量身打造的全方位互動測驗與聽讀學習系統。  
> 完整收錄期中考真題 40 問、平假名/片假名五十音圖表、濁音與拗音、日常實用 8 大會話、數字聽讀選，並內建自然真人語音朗讀與個人錯題筆記本。

---

## 🌟 系統特色與核心功能

### 1. 期中考全真原題 40 問實戰模擬（100 分制）
* **平假名 20 題**：完整還原測驗題目（何、犬、猫、母、十、百円、鉛筆、水、寮、日本、雑誌、牛乳、病院、名前、靴、玉子、弟、先生、音楽、今日）。
* **片假名 20 題**：完整還原測驗題目（coffee、cake、convenience store、hamburger、toilet、milk、mask、necktie、携帯電話、card、ice cream、elevator、拉麵、notebook、hotel、taxi、supermarket、sheet、shirt、bed）。
* **雙向發音支援**：題目可聽發音，每個選項旁亦設有喇叭鍵，可點擊試聽選項微小發音差異（如 `りょう` vs `りよう`、`ベッド` vs `ベット`）。
* **詳細詳解與記憶口訣**：每題作答後即時揭曉羅馬拼音、漢字假名、易混淆分析與記憶小口訣。

### 2. ★ 第 9 題「寮（りょう）」弱點突破
針對前測中失分（0/5 點數）的關鍵題進行深度拆解：
* **「寮」的正確讀音**：`りょう (ryō)` —— 屬於**拗長音（小寫 ょ ＋ 長音 う）**，發一拍半。
* **混淆選項解析**：
  * ❌ `りよう (riyou)`：大寫「よ」，為三個音拍的「利用」！
  * ❌ `りゅう (ryū)`：為「龍」或「流」。
  * ❌ `りゆう (riyuu)`：為「理由」。
* 系統預設將此題加入「錯題筆記本」，方便考前快速重複刷題直到 100% 掌握。

### 3. 五十音平片假名全圖表與聽力辨識
* **音系完整收錄**：清音（あ~ん / ア~ン）、濁音（がざだば）、半濁音（ぱ）、拗音（きゃ、しゃ、にゃ、ひゃ、りょ等）。
* **三種對照檢視模式**：平片並列、只看平假名、只看片假名。
* **點擊即讀**：點擊任意假名方格即可由真人原音即時朗讀。
* **片假名四大魔王終極圖解**：
  * **シ (shi) vs ツ (tsu)**：計程車是「タク**シ**ー」，床單是「**シ**ー**ツ**」。
  * **ソ (so) vs ン (n)**：漢堡是「ハ**ン**バーガー」，拉麵是「ラーメ**ン**」。
  * **ス (su) vs ヌ (nu)**：口罩是「マ**ス**ク」，冰淇淋是「アイ**ス**クリーム」。
  * **ベッド (bed)**：雙濁音＋促音組合（開頭ベ濁音、小寫促音ッ、結尾ド濁音）。

### 4. 日常實用 8 大會話與情境配對
* **早上好**：おはようございます（熟人間簡稱：おはよう）
* **你好 / 午安**：こんにちは（注意書寫為助詞「は」，讀為 wa）
* **晚上好**：こんばんは（注意書寫為助詞「は」，讀為 wa）
* **再見**：さようなら（長音「う」；同輩可用 じゃあね / またね）
* **謝謝**：ありがとうございます（敬體完整表達）
* **不好意思 / 借過**：すみません（叫服務生、道歉、借過萬用句）
* **麻煩你了 / 請多關照**：よろしくお願いします（自我介紹與請託壓軸）
* **我回來了**：ただいま（並附有屋內人的應答**「おかえりなさい（歡迎回來）」**配對試聽）
* *附贈生活禮儀：いただきます（我開動了）、ごちそうさまでした（多謝款待）、おやすみなさい（睡前晚安）*

### 5. 數字聽讀選特訓館（0～10,000）
* **基本數字 0～10**：特別提示 4（よん/し）、7（なな/しち）、9（きゅう/く）、10（じゅう 拗長音）。
* **期中考必考特殊音變**：
  * 300：さん**びゃく**（濁音音變）
  * 600：**ろっぴゃく**（促音 ＋ 半濁音音變）
  * 800：**はっぴゃく**（促音 ＋ 半濁音音變）
  * 3000：さん**ぜん**（濁音音變）
  * 8000：**はっせん**（促音音變）
  * 一萬：**いちまん**（前面必須加「いち」）
* **純聽力測驗題型**：題目自動播放日語數字語音（如「ろっぴゃく」），學生從 600、800、60、300 中聽音辨號。

### 6. 單字速查翻轉卡（Flashcards）
* 40 個期中考單字製成雙面互動卡片。
* 正面顯示漢字或英文外來語，點擊一鍵翻面查看平片假名讀音、羅馬拼音、中文意義與記憶口訣。

### 7. 個人錯題與弱點筆記本
* 自動將作答錯誤的題目收錄至 `localStorage` 本地儲存。
* 支援「一鍵重新測驗錯題」，直到全部答對並標記為已掌握。

### 8. 自然音訊發音引擎
* **🌟 Google 母語真人自然原音**（預設啟用，標準東京腔調，自然清晰流暢）。
* **系統自然女聲 / 男聲切換**：自動匹配作業系統中的高品質神經網路語音（Nanami / Kyoko / Keita / Otoya）。
* **語速自由切換**：提供 `0.75x 慢速`、`0.9x 標準`、`1.0x 正常`，方便初學者聽辨促音與拗音。
* **頂部「試聽發音」按鈕**：點擊可隨時驗證音色。

## 🛠️ 技術架構

* **前端框架**：React 19 + TypeScript
* **建構工具**：Vite 8
* **樣式庫**：Tailwind CSS v4 + 專屬日語字體渲染優化（Noto Sans JP / Kosugi Maru）
* **圖標庫**：Lucide React
* **發音引擎**：Google Natural Native Audio Engine + Web Speech Synthesis API 雙軌智能容錯
* **音效合成**：Web Audio API（非依賴外部音檔，零延遲即時合成正確鈴聲與錯誤提示音）
* **資料持久化**：瀏覽器 `localStorage`（記錄使用者錯題本與學習進度）

## 🚀 本地開發與執行

1. **安裝相依套件**：
   ```bash
   npm install
   ```

2. **啟動本機開發伺服器**：
   ```bash
   npm run dev
   ```
   瀏覽器開啟 `http://localhost:3000` 即可開始使用。

3. **建置正式發布版本**：
   ```bash
   npm run build
   ```

## 🎯 期中考考前衝刺建議

1. **第一步：先到「期中考全真測驗」做完整 40 題**，掌握平片假名題型的整體答題節奏。
2. **第二步：重點攻克「寮（りょう）」**，牢記小寫 `ょ` 是拗音，後面加 `う` 是長音（共一拍半），千萬不要選大寫的 `りよう`！
3. **第三步：進入「五十音發音表」查看片假名四天王**，特別分清 `シ`（微笑平躺）與 `ツ`（直立下墜）、`ン`（由下往上）與 `ソ`（由上往下）。
4. **第四步：切換到「數字聽讀選」**，把 300（さんびゃく）、600（ろっぴゃく）、800（はっぴゃく）的聽力題多聽兩次。
5. **第五步：考前回顧「錯題筆記本」**，把答錯的題目刷到全部掌握，期中考試保證穩拿滿分！
